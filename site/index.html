Four real friction points

Built for the problems that hit on day three, not minute one.

01

Drifting chat → Living reports & kernel-verified facts

Before: Decisions, scope changes, and test results vanish inside 400-line scrolling terminal logs.

With Perga: Conversation stays in the margin. The main pane is a read-only editorial report backed by kernel-stamped facts (actual model, gate exit codes, timestamps) that agents cannot forge.

02

Goldfish amnesia & auto-memory bloat → Governed shared memory

Before: Fresh sessions forget yesterday's architecture, while unchecked CLAUDE.md or auto-memory piles up conflicting rules and wastes context.

With Perga: Readable UTF-8 Markdown memory scoped by Area and Global, shared across Claude Code, Codex, and ACP. Task leads can only memory_propose; a dedicated Memory Planner enforces ETags and strict byte budgets.

03

One model grading its own homework → Cross-model separation & live Steer

Before: The same session writes code and declares victory, or background subagents run in a black box until they go off the rails.

With Perga: Enforce read-only review on a different provider (e.g., Claude implements, Codex audits), block completion on host test gates, and steer or swap models on the live worker stream at any time.

04

Token-burning loops & slow worktrees → 0-token watches & real local isolation

Before: Fragile bash scripts poll CI, Electron wrappers lag across 5 sessions, and every Git worktree cold-rebuilds your repo from scratch.

With Perga: Declarative flow.json probes CI or shell checks at zero token cost until state changes. Isolate tracks with Git worktrees, native Jujutsu (jj), Linux OverlayFS prewarmed caches, or remote SSH.

Local sovereignty

No cloud lock-in. Runs on your machine, with your CLIs.

Runtime
Self-contained .NET 11 Host (macOS arm64 & Linux x64) + lightweight Web/PWA (no Electron)
Terminals
Native Rust PTY bridge (perga-term-bridge, #![forbid(unsafe_code)]) — survives host restarts
Providers
Claude Code, Codex, and ACP-compatible CLIs via bundled OAR bridge — bring your existing subscriptions
Workspaces
Git worktrees, Jujutsu (jj), Linux OverlayFS prewarmed build snapshots, and remote SSH targets
State & Memory
Single local SQLite WAL database + plain UTF-8 Markdown memory files with ETag optimistic locking
Protocols
Start with zero templates; attach 27–40 line .perga.js protocols only when recurring rules emerge
