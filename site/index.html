HETEROGENEOUS ROUTING · SHARED WORKER CONTROL ZERO VENDOR LOCK-IN

Enforced Separation of Execution & Review

A single Lead coordinates workers across providers inside one isolated workspace. A 27-line .perga.js protocol enforces that implementation runs read-write behind a host gate, while review runs read-only on a different model. 

tasks: {
  routing: [
    { when: { role: "impl" },   access: "read_write", requireGate: true },
    { when: { role: "review" }, provider: "codex", access: "read_only", enforce: true }
  ]
}

SEC. 02 WHY NOT FIVE CLI TABS?
Designed for day three of a real task, not minute one.
01

Living reports over drifting chat

Scroll through 400 lines of terminal output to remember what changed.

Conversation stays in the side pane. The main view is a read-only editorial report combining schema-validated ledgers with kernel-stamped facts (actual model, gate exit codes, timestamps) that agents cannot forge. Context limits trigger native compaction or report-anchored epoch handover.

ReportDoc · Optimistic block locks · Epoch handover
02

Governed local memory over auto-memory bloat

Choose between goldfish amnesia and a 600-line polluted CLAUDE.md.

Durable knowledge lives as readable UTF-8 Markdown scoped by Area and Global, shared across Claude Code, Codex, and ACP. Task leads can only propose updates; a dedicated Memory Planner enforces ETags, hard byte budgets, and hash-deduplicated injection — plus @mention recall and one-click Save.

Area 1228 B · Global 820 B · Index 1024 B · ETag
03

Enforced cross-model review & live Steer

Let the same model write the code, weaken the test, and declare victory.

Orchestrate Claude Code, Codex, and ACP inside the same track. Execution is structurally separated from acceptance, reviews can be enforced read-only on a second provider, write tasks pass through host verification gates, and you can steer or swap models on the live worker stream anytime.

routing.enforce · Host Gate · Shared human/Lead Steer
04

0-token watches & real local isolation

Burn tokens polling CI or wait ten minutes per Git worktree rebuild.

Declarative flow.json runs zero-token probes (prChecks or shell commands) and wakes the Lead only when state changes. Isolate tracks via Git worktrees, native Jujutsu (jj), Linux OverlayFS prewarmed build snapshots, or remote SSH targets — with a persistent Rust PTY bridge.

0-token watch · Linux OverlayFS · Native jj · Remote SSH
SEC. 03 SYSTEM SPECIFICATIONS
100% local sovereignty. Zero cloud lock-in.
Host Binary
Self-contained .NET 11 native packages for macOS Apple Silicon (arm64) and Linux x64 (WSL2 supported). No .NET runtime required.
Frontend
Lightweight React + TypeScript web app & installable PWA — no Electron overhead across parallel sessions.
Terminal Bridge
Independent Rust daemon (perga-term-bridge, #![forbid(unsafe_code)]) — persistent PTY sessions survive host restarts and hot upgrades.
Agent Providers
Claude Code, Codex, and ACP-compatible CLIs via bundled OAR bridge (requires Node.js 24+). Use your existing provider subscriptions.
Workspaces
Git worktrees, Jujutsu (jj), Linux OverlayFS with shared prewarmed build caches, and remote SSH execution with reverse MCP tunnel.
Storage & Memory
Single local SQLite WAL database + readable UTF-8 Markdown memory files with frontmatter and ETag concurrency control.
Protocols
Zero-template start by default. Attach 27–40 line .perga.js protocols (agents-delivery, okr-loop, equity-research, memory) only when rules recur.
