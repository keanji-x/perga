# Perga 模板 Taste 与信息设计原则

> **核心信条**：模板不是用来让 AI“多画组件”的，而是用来约束 AI **少说废话、用最省墨的原语呈现读者此刻必须知道的结论**。

---

## 一、第一原则：做减法

每个入口、标签、列标题、提示语都必须先回答一个问题：**“读者此时是不是必须知道它？”** 不是，就删掉。

- **删掉多余操作入口**：由模板驱动的交付 Track 隐藏顶部 `Dispatch Worker` 按钮；Report Block 对人类只读（移除人类侧 `Edit` 按钮，由 AI 维护，人专注阅读与决策）。
- **删掉重复标签与冗余词**：
  - 署名只保留模型名（`Claude Opus` / `GPT 6.2 SOAR`），删掉重复的 `Worker #1` 前缀；点击模型名直接进入对应 Worker 对话。
  - 一维价格坐标轴上，低价在左、高价在右，位置本身已表达高低预期，删掉「悲观 / 中性 / 乐观」文字。
  - 短时间线删掉多余分类 Tab（`全部 / 财报 / 大事件`）；展开的正文不重复行首已展示的日期、状态与模型名。
  - 每个优化 Loop 里的 `Expect` 只写该次实验自身的局部验收指标，不重复抄写顶部的全局 KR。
- **删掉凑格子的装饰信息**：
  - 不为填满表格而编造「证据」列或空泛导语；
  - 趋势折线并非必选项——多数长期 OKR 里，**`更新时间`**（数据新鲜度）比一条装饰性小折线更有价值。

---

## 二、出版物美学（Swiss / Monograph）

契合 Perga 的纸面（`--paper` / `--bg`）与衬线阅读气质，刻意远离“SaaS 后台表单 / Grafana 监控大屏”：

- **排版层次替代容器盒子**：用衬线大标题、等宽数字/日期（`tabular-nums`）、1px 细线（`--hairline`）和字重对比建立层级，避免圆角卡片套卡片、发光进度球、高饱和彩色徽章。
- **去掉误导性下划线**：阶段选中态、时间线标题、模型署名均不加下划线（避免“可点击编辑”的误解），改用纯墨色与字重区分状态。
- **动态状态克制表达**：Gate 验证不做占屏大表，收口为紧贴正文底部的引用脚注行——`✓` 表示通过、**三点跳动动画**表示运行中、`×` 表示失败，仅在点击有日志的条目时轻展开单条脚注。

---

## 三、交互自然与引用原生化

- **拒绝 iframe 割裂**：阶段交付、坐标轴、时间线、KR 总账均用原生 DOM + 语义设计 Token 渲染，天然适配亮/暗双主题与容器响应式。
- **外部文档即正文蓝色文字引用**：不设独立的右上角「阅读原文 / 阅读全文」按钮；设计文档、财报拆解、事故复盘、源码模块均以标准 Markdown 蓝色文字引用内联在正文中（悬停预览、点击直达 Perga 原生文件阅读器）。
- **反事后诸葛亮（Gate 与 Expect 同构）**：软件交付靠自动化 **Gate** 锚定验收标准；投研事件与 OKR 实验靠事件前动态挂起的 **`Expect` 槽**，落地后对照 `事前预期 vs 实际兑现`，杜绝事后空泛复盘。

---

## 四、三类场景的视觉收敛对照

| 场景 | 顶部核心交付锚点 | 演进脊柱 | 校验机制 |
|---|---|---|---|
| **单向软件交付**（`AGENTS.md`） | 1 句 Target Markdown | 横向细线 `stepper`（有限阶段） | 脚注式 **Gate**（测试 / Lint） |
| **长期投研**（NVDA） | 一维比例价格坐标轴（现价在轴上、目标价在轴下、悬停看假设） | 纵向 `chronicle`（日期 · 标题 · 模型 · 结论）+ 下方常青分析正文 | 动态 **`Expect` 槽**（事前预期 vs 实际兑现） |
| **长期 OKR Loop**（CI/CD） | 1 句稳定 Objective + 混合型 KR 四列总账（`KR \| 当前 \| 目标 \| 更新时间`） | 分组 Loop Roadmap（`当前优化` / `下一轮优先级队列` / `已闭环含回滚`） | 局部实验 **Expect** + 每日静默 Check |
