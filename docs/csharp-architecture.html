1. 彻底解毒「多 Harness 恶心 Corner Case」

  • 病因诊断：老版去调各家私有的 /compact、手拼 Claude 的 Edit(//path/**)（路径带括号就炸）、塞 Codex 的 shell_environment_policy（冲掉内置 rg），导致 CLI 升小版本就崩。
  • 解法 ① 宿主自管换页压缩（消灭原生 Compaction 差异）：上下文超限时，发一条普通对话让 Agent 输出结构化交接摘要，随后直接关闭旧底层 Thread、用「交接摘要 + 最新 Report」开新底层 Thread（前端仍是同一 SessionId）！100% 通用，0 私有压缩协议！
  • 解法 ② 沙箱外置给 OS Wrapper（消灭 CLI 权限语法坑）：底层 CLI 统一以纯协议模式启动；隔离交给外层统一的 bwrap (Linux) / sandbox-exec (macOS)，高危业务工具交给 MCP DSL 拦截，与哪家 CLI 完全解耦！
  • 解法 ③ 全面对齐 ACP 最小 4 原语：Antigravity / OpenCode 原生走 ACP；Claude 与 Codex 优先走现成官方/社区 ACP 桥（claude-agent-acp / codex-acp）或极薄 4 原语管道（Start / Prompt / Cancel / Approve），严禁碰各家私有子命令！

2. Terminal 桥接：直接提纯复用你现有的 rmux 解析栈

  • 源码核查结论：不仅能复用，而且新版写得非常地道！老仓库之所以重，是因为同时留着旧版（calm-session 的 vte 手写网格 + legacy_*）和新版（calm-terminal-view + calm-terminal-runtime + terminal_interaction）两套实现。
  • 直接保留复用的精华：
    1) calm-terminal-view (234行, forbid(unsafe_code))：基于 rmux-core，宽字符对齐、Alternate Screen 菜单识别、Bracketed Paste 模式感知、防重复终端应答都已经打磨好了，且纯内存天然跨 Linux/macOS/Windows！
    2) terminal_interaction 核心算法：row_hashes 屏幕静默稳定检测 (settle_ms)、text_wait 与自适应按键编码直接剥离 RouteRepo 复用！
    3) 跨系统 PTY 底座：Linux/macOS 直接跑现有的 calm-terminal-runtime (rmux-server，把 Linux 专属 unshare 改为按平台可选，自带热重启不断连)；Windows 只需用 portable-pty (ConPTY) 读字节喂给同一个 TerminalView！

3. 务实插件方案 + 原生一等支持 jj (Jujutsu)

  • 为什么 JJ 是多 Agent 天选 VCS：
    · 无暂存区，工作区自动即 Commit (@)：彻底省掉老版 5,300 行自动 git add/commit 候选状态机！
    · 稳定 ChangeId + jj workspace add：多 Track 并行无需抢分支名；jj op restore 一键原子回滚失控 Worker！
    · 一等公民冲突：jj rebase -d main@origin 永远成功返回 0 不卡死，冲突存进树里直接派 Task 解决；开启 --colocate 后与 gh / Cargo 100% 兼容！
  • 首期插件极简务实化：
    · 内置核心直接编译进 C#：vcs_jj（原生 JJ + Git 兜底 + gh PR/Issue）、terminal、source（网页/研报存证）。
    · 常用外部 MCP 静态直挂：读一份简单的 mcp-plugins.json，把你常用的智堡 Wisburg、以及老仓库现成编译好的 market 二进制直接挂进来即可，首期不做复杂插件安装器！
